# Winning Metrics Framework

Tim Connors' (PivotNorth Capital) framework for measuring what matters at each stage of a startup. The framework is sequential — you must pass each stage before advancing.

## The Progression

**WM0: Does it work?** → Product is live, users complete core flow successfully, measurable value delivered.

**WM1: Do users love it?** → NPS score. Promoters tell you what to feature in marketing. Detractors tell you what to fix. Sean Ellis PMF score as complement.

**WM2: Do users stick around?** → Retention asymptote chart. X-axis = months since acquisition, Y-axis = % retained. The asymptote height is your signal. Plot by cohort (darkest = newest) to see if you're improving.

**WM3: Will customers pay more than it costs to reach them?** → CAC Doubling Time (CACD). Turn $1 of S&M into $2 of gross margin. Target: CACD ≤ 8 months, LTV/CAC ≥ 5x. This is where 99% of startups fail.

**WM4: How far have you scaled?** → Once WM0-3 work, scale from $1M → $5M → $30M → $100M ARR. Monitor unit economics at each doubling.

## How to Use This Skill

When evaluating any product or business decision, first identify which WM level the company is operating at. Then apply the appropriate lens:

- If WM0 isn't proven, no other metric matters. Ship the core experience.
- If WM0 works but WM1 is weak, fix the product before spending on growth.
- If WM1/WM2 are strong but WM3 is unproven, run 6 months of systematic weekly A/B testing on channels before concluding.
- If WM0-3 all work, the only question is how fast to pour fuel on the fire (WM4).

The cardinal sin: spending on WM3 (growth) before WM1 (love) is proven. You'll burn cash acquiring users who churn.
